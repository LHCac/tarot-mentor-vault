# Spreads

本資料夾是之後算牌時的主要牌陣庫。每個牌陣定義用途、張數、位置功能、適用情境、限制與解讀順序；單張牌義仍放在 `knowledge/cards/`，不在牌陣檔重複保存。

## 預設選擇順序

沒有指定牌陣時，先使用能回答問題的最少張數：

1. 每日提醒或單一焦點：`one-card-reflection.md`。
2. 一般工作、學習、人際與成長問題：`three-card-guidance.md`，這是預設主牌陣。
3. 不知道真正卡點：`three-card-problem-solving.md`。
4. 想看一段時間的發展：`three-card-timeline.md`。
5. 想整理自己的內外一致性：`three-card-self-alignment.md`。
6. 快速看關係：`three-card-relationship-snapshot.md`。
7. 階段回顧或習慣調整：`three-card-stop-start-continue.md`。
8. 比較兩個明確選項：`five-card-two-choice.md`。
9. 關係涉及雙方、內外阻力與發展潛力：`seven-card-relationship.md`。

## 完整三張牌選單

`three-card-library.md` 收錄 25 組三張牌結構。使用者已指定其中一組時，直接依該組牌位；未指定時，由導師依上面的順序推薦，不為了讓答案看起來更豐富而增加張數。

## 共通規則

- 抽牌前先固定問題、時間範圍與牌位，抽牌後不改位置。
- 未來或結果牌都是目前條件下的趨勢，不是保證。
- 對方牌位只描述可觀察互動，不替第三人讀心。
- 原則上一個位置最多補一張，補牌前先寫明要釐清的單一問題。
- 同一問題不因不喜歡答案而短時間反覆更換牌陣或重抽。

新牌陣請從 `schemas/spread-template.md` 複製，避免同一個位置名稱在不同檔案中代表不同意思。
