# 可以直接使用的提問範例

## 讓導師推薦牌陣

```text
【模式】算牌
【我的問題】我想問……
【時間範圍】未來一個月
【牌陣】請從主要牌陣庫推薦最合適、張數最少的一種
【分析重點】個人成長／行動建議
【回答方式】完整分析／一邊教學
```

導師會先推薦牌陣與列出每個位置；確認牌位後再依順序抽牌。若你已經抽好牌，請把牌名、正逆位與對應位置一起貼上。

## 單牌解讀

```text
請用塔羅導師資料庫解讀一張牌。
問題：我這週工作上最值得注意什麼？
抽到：權杖六，逆位。
請分成資料記載、情境推論、可觀察訊號與一個實際行動，最後列出牌卡 ID。
```

## 三牌解讀

```text
請使用「現況・阻力・方向」三牌牌陣。
問題：我該如何推進目前的個人計畫？
1 現況：魔術師正位
2 阻力：隱者逆位
3 方向：權杖三正位
請先逐牌，再整合；若使用大秘儀組合資料，標出 A → B 的方向。不要把第三張說成必然未來。
```

## 五張二擇一

```text
請使用「五張二擇一」牌陣。
問題：未來三個月，我選擇 A 或 B，各自需要什麼投入與準備？
1 選擇核心：＿＿＿
2 A 的發展：＿＿＿
3 B 的發展：＿＿＿
4 A 的提醒：＿＿＿
5 B 的提醒：＿＿＿
請分別整理 A 與 B 的條件、代價和可驗證訊號，不替我作決定。
```

## 七張關係全貌

```text
請使用「七張關係全貌」牌陣。
問題：未來一個月，這段關係的互動重點與我能調整的方向是什麼？
1 關係現況：＿＿＿
2 我的感受與需要：＿＿＿
3 對方呈現的互動態度：＿＿＿
4 內在重複模式：＿＿＿
5 外在現實條件：＿＿＿
6 我的行動建議：＿＿＿
7 目前路線的發展潛力：＿＿＿
請不要把第 3 張當成讀心，也不要把第 7 張說成命定結果。
```

## 學一張牌

```text
請當我的塔羅老師，教我「女祭司」。
先用圖像、核心動詞、正逆位差異與一個生活例子教學；接著只出一題讓我回答，等我答完再回饋，不要一次公布答案。
```

## 比較容易混淆的牌

```text
請比較「力量」與「戰車」。
用動機、行動方式、陰影面、適合出現的問題情境做對照，最後出一題情境判斷題讓我練習。
```

## 複習測驗

```text
請只從目前資料庫已有的 22 張大秘儀、14 張權杖與 14 張聖杯出五題漸進式測驗。一次只出一題；每次回饋要指出我觀察正確的地方、需要補強的地方，以及另一種合理解法。
```
