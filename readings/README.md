# 問牌紀錄

這個目錄保存可回顧、可學習的解牌案例，讓資料庫不只記錄牌義，也能比較「當時的解讀」與「後來的實際發展」。

## 隱私分層

- `templates/`：可直接複製的空白紀錄模板，可以公開。
- `examples/`：移除姓名、機構名稱與敏感背景後的匿名案例，可以公開。
- `private/`：包含完整個人情境的原始紀錄，只留本機，已由 `.gitignore` 排除。

公開案例不得包含姓名、聯絡方式、公司或學校名稱、精確地點、帳務資料、病歷，以及足以辨認當事人的關係細節。無法確定是否安全時，一律放入 `private/`。

## 建議流程

1. 先用 [`templates/reading-record.md`](templates/reading-record.md) 建立私人原始紀錄。
2. 寫清楚問題、時間範圍、牌位與正逆位。
3. 把解讀分為逐牌、整合、行動建議與不確定性。
4. 到期後補寫實際發展，不用事後修改原始解讀。
5. 值得教學的案例經匿名化後，另存到 `examples/`。

案例的作用是練習與反思，不是證明塔羅能保證特定結果。健康、法律、財務與心理危機等議題，仍應尋求合格專業人士的協助。
