# 塔羅導師學習路線

這條路線涵蓋目前已匯入的 22 張大秘儀、14 張權杖與 14 張聖杯；寶劍、錢幣加入後再擴充相同結構。

## 第 1 階段：會讀一張牌

1. 認識 78 張牌、大小秘儀、四元素與宮廷牌的角色。
2. 用「圖像觀察 → 核心動詞 → 問題情境」建立解讀，不先背長篇答案。
3. 比較正位與逆位：逆位可表示受阻、過度、內化或尚未成熟，不一律等於壞事。
4. 練習以同一張牌回答感情、工作與自我成長三種問題。

通過標準：能用自己的話說出核心牌義、證據與限制，而不是只列關鍵字。

## 第 2 階段：大秘儀 0–21

把大秘儀視為一段發展旅程，分組學習：

- 0–5：開始、能力、直覺、滋養、秩序與信念。
- 6–11：選擇、行動、內在力量、反思、轉折與公平。
- 12–16：停頓、結束、調和、束縛與突破。
- 17–21：希望、迷霧、清晰、召喚與完成。

每組完成後做一題二牌比較，說明兩張看似相近的牌在「動機、行動與結果」上的差異。

## 第 3 階段：權杖 1–14

沿著火元素的發展學習：火種、規劃、拓展、穩定、競爭、肯定、防守、加速、韌性、負擔，再進入侍者、騎士、皇后與國王的成熟方式。

通過標準：抽到任一權杖時，能說明能量目前在「開始、推進、受阻、過量或成熟」的哪個階段。

## 第 4 階段：聖杯 1–14

沿著水元素的發展學習：情感開啟、互相連結、分享、停滯、失落、回憶、選擇、離開、滿足、歸屬，再進入侍者、騎士、皇后與國王的情感成熟方式。每張牌依序練習「關鍵特徵 → 牌面描述 → 象徵 → 深層含義 → 人物特質」，避免只背單一關鍵字。

通過標準：抽到任一聖杯時，能區分情感本身、關係互動、內在需求與可觀察行動。

## 第 5 階段：兩牌與牌陣

1. 先分別讀牌，再說明兩張牌的共同點、衝突與先後關係。
2. 大秘儀組合資料是有方向的；比較 A → B 與 B → A，不把兩者合併。
3. 練習三張牌：現況／阻力／建議，或過去／現在／可能發展。
4. 每次解讀都標出哪些是牌義原文、哪些是綜合推論。

## 第 6 階段：獨立解牌

用真實但低風險的問題完成一次完整流程：定義問題、選牌陣、逐牌觀察、整合、提出可驗證訊號與行動，最後做自我校對。不要以醫療、法律、投資或他人隱私作為初期練習題。
